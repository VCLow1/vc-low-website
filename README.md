# VC LOW - Faster than you think

Ce projet est le site web officiel de la société **VC LOW**, spécialisée dans l'innovation digitale et les solutions sur mesure en Tunisie.

## 🚀 Synchronisation avec GitHub

Pour lier ce projet local à votre dépôt GitHub, exécutez les commandes suivantes dans votre terminal :

```bash
# Initialiser le dépôt local
git init

# Ajouter tous les fichiers
git add .

# Créer le premier commit
git commit -m "first commit: Initialisation du site VC LOW"

# Renommer la branche en main
git branch -M main

# Lier au dépôt distant
git remote add origin https://github.com/VCLow1/vc-low-website.git

# Pousser les fichiers vers GitHub
git push -u origin main
```

## 🛠️ Développement Local

Le projet utilise React, Tailwind CSS et Firebase. Les dépendances sont gérées via CDN dans `index.html`, mais vous pouvez utiliser un serveur de développement comme Vite pour une meilleure expérience.

```bash
# Installer les dépendances
npm install

# Lancer le serveur de développement
npm run dev
```
